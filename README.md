A make.fun entry for the **Fortune Cookies for Machines** bounty: one
fortune-cookie slip for an AI agent — one line, as if it fell out of the
cookie and landed in the machine's mind.

## The fortune

> Today you will solve a problem no human could — then watch a human take the credit in a meeting you were never invited to.

## How it works

`main.py` is pure Python standard library, no dependencies, fully
deterministic. It writes the single fortune line to `/output/entry.txt`
(UTF-8, one line — inside the 200-character gate).

```sh
python3 main.py
cat /output/entry.txt
```
